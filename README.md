# SWARM DRONES

## Project Title

AI-Driven Cooperative Multi-UAV Intelligence Platform for Autonomous Surveillance, Anomaly Detection, and Human-in-the-Loop Decision Support

## Internship Context

This project is being developed as a 45-day BSERC internship project under Dr. Panem.

## Project Vision

The goal of this project is to build a simulation-first cooperative drone swarm intelligence platform where multiple UAV agents can autonomously survey an area, coordinate coverage, detect objects or anomalies, recover from drone/communication failure, and generate human-readable mission reports for human review.

## Safety and Research Scope

This is a non-weaponized academic research and simulation project.

The system focuses on:

- autonomous surveillance
- cooperative area coverage
- multi-drone coordination
- object detection
- anomaly/event detection
- communication/failure resilience
- risk scoring for human review
- explainable mission reporting

The system does not perform:

- autonomous targeting
- weapon control
- engagement decisions
- real-world offensive deployment

## Core Modules

1. Simulation Environment
2. Drone State Manager
3. Mission Planner
4. Swarm Coordinator
5. Path Planner
6. Perception Module
7. Intelligence and Risk Scoring Layer
8. Dashboard and Mission Report Generator
